# Good Food Restaurant

A responsive landing page for a food restaurant, built with plain HTML and CSS. It showcases featured dishes and partner brands, highlights ongoing deals and invites visitors to follow the restaurant on social media.

## Features

- **Hero section** with a full-width background image, headline and call-to-action button.
- **Featured deals** presented as cards for pizza, kacchi biryani and burgers.
- **Social section** with Facebook, X, Instagram and Pinterest icons.
- **About section** pairing a food image with the restaurant's message.
- **Responsive layout** that adapts from large desktop screens down to mobile phones.

## Tech stack

- HTML5
- CSS3 (Flexbox, media queries)
- [Work Sans](https://fonts.google.com/specimen/Work+Sans) from Google Fonts

## Project structure

```
food-restaurant-project/
├── index.html        Page markup
├── style/
│   └── style.css     Styles and responsive rules
└── assets/           Images and icons
```

## Getting started

No build step or dependencies are needed.

1. Clone the repository:

   ```bash
   git clone https://github.com/rabeyanoor/food-restaurant-project.git
   cd food-restaurant-project
   ```

2. Open `index.html` in your browser, or serve the folder locally:

   ```bash
   python3 -m http.server 8000
   ```

   Then visit `http://localhost:8000`.
